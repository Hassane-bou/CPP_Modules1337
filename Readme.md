# C++ Modules — 42 / 1337

## 📚 Overview

This repository contains the C++ modules from CPP00 to CPP09, completed as part of the 42 / 1337 curriculum.

The goal of these modules is to learn Object-Oriented Programming (OOP) in C++98, from the basics to more advanced concepts such as inheritance, polymorphism, templates, and the Standard Template Library (STL).

## 🗂️ Modules

| Module | Topics | Description |
|---|---|---|
| **CPP00** | Classes, Objects, Namespaces, I/O | Introduction to C++, classes, member functions, and basic input/output. |
| **CPP01** | Memory Allocation, Pointers, References | Learn about memory allocation, pointers, references, and object lifetime. |
| **CPP02** | Ad-hoc Polymorphism, Operator Overloading | Introduction to fixed-point numbers, canonical form, and operator overloading. |
| **CPP03** | Inheritance | Learn inheritance and how classes can extend other classes. |
| **CPP04** | Subtype Polymorphism, Abstract Classes, Interfaces | Explore virtual functions, abstract classes, and interfaces. |
| **CPP05** | Repetition and Exceptions | Learn exception handling, try/catch blocks, and custom exceptions. |
| **CPP06** | C++ Casts | Understand static, dynamic, reinterpret, and const casts. |
| **CPP07** | C++ Templates | Learn function templates and class templates. |
| **CPP08** | Templated Containers, Iterators, Algorithms | Explore STL containers, iterators, and algorithms. |
| **CPP09** | STL | Practice using standard containers to solve algorithmic problems. |

## 🛠️ Technologies

- **Language:** C++98
- **Compiler:** `c++`
- **Compilation flags:** `-Wall -Wextra -Werror`
- **Build system:** Makefile

## 🚀 Compilation

Each exercise contains its own `Makefile`.

Navigate to the desired exercise directory and run:

```bash
make
```

Run the compiled program:

```bash
./program_name
```

Clean object files:

```bash
make clean
```

Remove object files and the executable:

```bash
make fclean
```

Recompile everything:

```bash
make re
```

- Understand Object-Oriented Programming.
